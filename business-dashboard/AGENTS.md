# AGENTS.md · 协作契约

> 任何 AI agent 或协作者在改动本项目前，必须先读完本文件与 `ARCHITECTURE.md`。
> 本文件中的「禁止」是硬约束，不要因为"技术上能做到"就绕过。

---

## 1. 项目定位

单用户的本地业务项目看板。一个人在 Windows / macOS 上用它记录并查看 5～6 个海外项目的状态、卡点、下一步和关键日期。

**不是** SaaS，**不是** 团队协作工具，**不是** 数据平台。任何让部署变复杂、让数据离开本机的改动，无论多优雅，都是错的方向。

---

## 2. 技术红线

### 2.1 前端

| 禁止 | 原因 |
|---|---|
| 引入 Vite / React / Vue / 构建步骤 | 前端必须能双击 `index.html` 直接用，`file://` 下无构建产物可运行 |
| 用 `<script type="module">` | `file://` 下会因 CORS 直接失败，离线模式报废 |
| 引入 CSS 框架或改现有 CSS 变量 | 视觉已由用户确认，改版需用户明确要求 |
| 重写 `renderBoard` / `renderCalendar` 的渲染逻辑 | 现逻辑可用，重写只带来 bug。只在数据来源处动刀 |
| 引入 `fetch` 之外的网络库 | 保持零依赖 |

允许：普通 `<script src>`、原生 `fetch`、现有 CSS 变量与类名复用。

### 2.2 后端

| 禁止 | 原因 |
|---|---|
| 引入 ORM（SQLAlchemy 等） | 表结构简单，直接 `sqlite3` 更可控，且少一层依赖风险 |
| 引入迁移框架（Alembic） | 用 `schema_meta.version` + 手写迁移，够用且零依赖 |
| 引入需要编译的包 | Windows 公司电脑装不上 |
| 依赖数量超过 5 个 | 每多一个依赖，明天少一分成功率 |
| 绑定 `0.0.0.0` | 同网段他人可直接访问，无鉴权等于裸奔 |

当前依赖白名单：`fastapi`、`uvicorn`、`pydantic`。要加第 4 个，先说明为什么标准库做不到。

### 2.3 数据

| 禁止 | 原因 |
|---|---|
| 把 `raw_text`、客户名、项目名写进日志 | 日志可能被同步/上传 |
| 把真实数据提交进 git | 含真实客户信息 |
| 未经用户逐次确认就调用任何外部 API | 客户名单出网是合规红线 |
| 硬 `DELETE` 用户数据 | 一律软删除（`archived=1`），保留恢复可能 |

## 3. 三条数据铁律

改任何涉及持久化的代码前，对照这三条：

1. **写前有备份。** 任何 schema 迁移、批量导入、`replace` 模式导入，之前必须 `VACUUM INTO` 或复制一份 `.bak`。
2. **写操作用事务。** 一次业务操作（如"新建项目 + 3 个里程碑 + 标记已完成阶段"）必须在一个事务里，失败全部回滚。不允许出现"项目建了但里程碑丢了"。
3. **后端不可用时前端必须仍能用。** 任何时候 `store.js` 探测不到后端，都要静默降级到离线模式并提示导出备份，**不能白屏、不能报错弹窗**。

## 4. 目录职责

| 路径 | 职责 | 改动注意 |
|---|---|---|
| `index.html` | 唯一前端。结构 + 样式 + 渲染 | 只改 `<script>` 里的数据来源；HTML/CSS 不动 |
| `assets/store.js` | 数据层抽象，双模式切换唯一入口 | 新增数据操作必须同时实现两种模式 |
| `assets/local-parse.js` | 离线模式解析 | 与 `app/parsing/local_rules.py` 算法保持一致 |
| `assets/md-import.js` | MD 切块、抽取、内容哈希 | 纯前端，不引后端；改抽取规则要同时验证幂等（同一份导两次不重复） |
| `app/schemas.py` | 请求模型 | **加字段必须同时加这里**，否则 Pydantic 会静默丢弃（踩过一次：orders 全丢） |
| `app/main.py` | 应用装配、静态托管、安全守卫 | 守卫不可削弱 |
| `app/settings.py` | 跨平台路径 | 数据目录必须在用户目录下，不在项目内 |
| `app/db.py` | 连接、schema、迁移 | 只增不删；加列走 `ADDED_COLUMNS` |
| `app/routes/*.py` | HTTP 层，薄 | 业务逻辑下沉到 service，路由只做校验与序列化 |
| `app/parsing/*` | 解析引擎 | 纯函数，不碰数据库，便于单测 |
| `app/providers/*` | 外部模型调用（P2 才启用） | 密钥只在服务端，永不回传前端 |
| `scripts/*` | 启动与自检 | 脚本失败必须给出人类可读的下一步 |

> 不设 `docs/` 子目录。接口契约与表结构统一写在 `ARCHITECTURE.md`，避免两处维护、两处不一致。

## 5. 修改流程

**改之前：**

1. 读 `ARCHITECTURE.md` §4（数据模型）与 §6（API 契约）
2. 确认要改的文件在 §4 目录职责里的归属
3. 若动 schema 或 API 形状，先确认前端调用点，一起改

**改之后，必须跑：**

```bash
python scripts/smoke.py               # 12 项断言全绿
```

并手工验证这三条（不能只靠自动化）：

- [ ] 双击 `index.html`（`file://` 直开）页面正常渲染，顶部显示「离线模式」
- [ ] 通过 `http://127.0.0.1:8787` 打开，顶部显示「后端模式」
- [ ] 新建一个项目 → 刷新页面 → 数据还在

**若改了前端视觉，必须**：改前截图、改后截图，对比确认无意外位移。

## 6. API 形状兼容性

`GET /api/bootstrap` 返回的项目对象必须与前端 `DB.projects[]` 元素**字段完全一致**（见 `ARCHITECTURE.md` §6.2）。

新增字段可以，**改名或删除字段不行**——那会静默破坏渲染而不会报错（`esc(undefined)` 只是显示空）。

修改出口形状时，同步改 `app/routes/data.py` 的 `to_client()`，并在 `ARCHITECTURE.md` §6.2 更新字段说明。

## 7. 代码风格

- Python：标准库优先；类型标注写在函数签名上；函数短小；错误信息面向使用者（中文，说清"发生了什么 + 该怎么办"）
- JS：ES2020 语法但**不用**可选链之外的实验特性；不引入 polyfill；不用 `var`
- 注释：解释**为什么**，不解释**做了什么**。`// 增加 3px` 是无用注释；`// 防止月份切换时 today 线残留` 才有价值
- 中文文案：说人话，不用"系统提示""操作成功"这类空话。用"已保存，刷新后还在"这种能验证的表述

## 8. 错误处理约定

| 场景 | 做法 |
|---|---|
| 用户输入非法 | 前端就地提示，不发请求；后端仍要校验（前端不可信） |
| 后端 4xx | 前端 toast 显示 `error.message`，不弹 alert |
| 后端 5xx / 网络失败 | 降级到离线模式，顶部横幅提示，**不丢用户已填内容** |
| 解析失败 | 返回空 ParseResult + `warnings`，让用户手填，不报错 |
| 数据库损坏 | 启动时检测 `PRAGMA integrity_check`，失败则重命名旧库并新建，提示用户旧库位置 |

## 9. 常见坑（踩过就别再踩）

1. **`file://` 下 `fetch` 一律失败**，包括 `fetch('./data.json')`。离线模式的数据只能来自 localStorage。
2. **`<script type="module">` 在 `file://` 下必然 CORS 失败**，所以 `store.js` 必须是普通 script，且不能 `export`。
3. **`localStorage` 在 `file://` 下按文件路径隔离**。把 `index.html` 换个文件夹，数据就"没了"——这不是 bug，要提前告诉用户。
4. **Excel 打开 UTF-8 CSV 会乱码**，除非带 BOM（`\xef\xbb\xbf`）。
5. **Windows 批处理里中文路径 + 非 ASCII 会乱码**，`.bat` 文件必须存为 GBK 或全用 ASCII，路径变量不要拼接中文。
6. **阶段改名会让 `done_phases` 悬空**，`PUT /api/phases` 必须按新列表清理，逻辑对齐前端 `savePhases()`。
7. **日期字符串比较**：`'2026-9-1' < '2026-10-01'` 为真，必须零填充成 `YYYY-MM-DD` 再比较。
8. **`new Date('2026-11-24')` 按 UTC 解析**，在东八区可能显示成前一天。日期一律用字符串操作，不要走 Date。
